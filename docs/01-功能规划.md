# 好大一颗菜 · 电子菜单小程序 — 完整功能规划（v2）

> 参考小程序「电子菜单 - 好大一颗菜」。
> 定位：**家庭/小聚场景的多人协同点菜 + 厨师接单工具**。
> 核心原则：**不涉及支付**，是美食记录与烹饪协作工具，不是商家收款系统。

---

## 一、产品定位

| 维度 | 说明 |
|------|------|
| 一句话 | 一日三餐，就用好大一颗菜——团队一起点菜，一键发给厨师 |
| 目标场景 | 家庭日常做饭、朋友小聚、情侣做饭、社团聚餐 |
| 核心价值 | 解决"今天吃什么"的决策难题 + 多人协同点菜不重复不遗漏 + 厨师清楚要做什么 |
| 不做什么 | 不做支付、不做外卖配送、不做商家收款、首版不做会员、首版不做社区 |

---

## 二、角色体系（三角色）

| 角色 | 职责 | 关键操作 |
|------|------|----------|
| **点菜人**（默认） | 选菜、下单 | 浏览菜单、加购物车、团队内一起点、提交订单 |
| **厨师** | 接收菜单、做菜 | 查看收到的订单、管理做菜进度、标记完成 |
| **组织者** | 管理团队 | 创建团队、邀请成员、指定厨师、最终确认下单 |

> - 一个用户可同时是点菜人和厨师（如家庭场景：妈妈点菜也是她做菜）。
> - 厨师确定方式：**两种都支持**——团队可固定指定某人当厨师，也可以点完菜后由成员"认领"做菜任务。

---

## 三、团队模型

| 概念 | 说明 |
|------|------|
| **团队** | 持久化组织，如"我家"、"美食社团"、"室友团"。成员相对固定。 |
| **团队成员** | 组织者邀请加入，成员可退出。一个用户可加入多个团队。 |
| **团队内点餐** | 在团队内直接发起点餐，所有成员可见、可参与，不需要单独创建"活动"。 |
| **团队厨师** | 团队可指定固定厨师（如妈妈），也可每次点餐后由成员认领。 |

> 与"临时房间"的区别：团队是长期组织，点餐是团队内随时发生的日常行为，成员不需要每次重新邀请。

## 四、核心功能模块

### 模块 1：点菜（核心中的核心）

#### 1.1 菜品浏览
- 分类切换：荤菜 / 蔬菜 / 汤羹 / 主食 / 能量补给 / 凉菜 …
- 菜品卡片：图片、名称、评分、价格（仅参考）、简介
- 搜索：按菜名/食材搜索
- 菜品详情：大图、食材清单、做法步骤、评分、加入购物车

#### 1.2 团队多人协同点菜
- **团队内点餐**：选择团队后发起点餐，团队成员可见可参与
- **实时同步**：所有人看到的购物车实时同步，谁点了什么一目了然
- **防重复提示**：同一道菜被多人点时提示"已有3人点了这道菜"
- **点菜人列表**：显示当前参与点餐的成员及各自点的菜

#### 1.3 智能辅助
- **随机点菜**：不知道吃什么？一键随机推荐 N 道菜
- **饮食计划**（后置）：根据人数、营养均衡推荐搭配

#### 1.4 购物车 & 下单
- 购物车：汇总所有菜品、数量、可调整
- 下单：生成订单 + **取餐码**
- 订单状态：待接单 → 制作中 → 已完成

---

### 模块 2：订单与取餐码

#### 2.1 取餐码设计 ⭐
- **是什么**：订单的简短编号（如 1002），便于口头沟通。
- **用途**：厨师做完后凭码通知"1002好了"，点菜人凭码确认取餐。
- **本质**：方便沟通的订单短号，不是餐厅叫号屏。点菜人和厨师之间的快速对暗号。

#### 2.2 订单详情
- 菜品清单、数量、点餐时间
- 取餐码
- 点餐人信息（用户ID/昵称）
- 订单状态流转

#### 2.3 订单操作
- **分享订单**：发给厨师（小程序卡片/图片）
- **复制订单信息**：纯文本，方便发微信群
- **发送给厨师**：厨师端收到通知并接单

#### 2.4 订单历史
- 历史订单列表
- 再次点同样的菜（一键复购）

---

### 模块 3：厨师端

#### 3.1 接单看板
- 收到的订单列表（按时间/状态排序）
- 订单详情：要做什么菜、各几份、取餐码
- 接单 / 拒单

#### 3.2 制作进度管理
- 状态流转：待接单 → 已接单 → 制作中 → 待取餐 → 已完成
- 标记单道菜完成
- 通知点菜人进度

#### 3.3 厨师视角特色
- **按菜品聚合**：相同菜合并做（如 3 份西兰花一起炒）
- **食材汇总**：多份订单的食材合并成采购清单

---

### 模块 4：菜谱与菜品管理

#### 4.1 菜谱库
- 平台预设菜谱 + 用户自定义
- 菜谱详情：食材、步骤、小贴士、图片
- 收藏、评分

#### 4.2 我的厨房
- **厨房管理**：管理自定义菜品/菜谱
- **厨房冰箱**：记录现有食材，推荐能做的菜
- **厨房菜篮**：待采购清单

#### 4.3 菜品发布
- 用户可上传自己的菜谱（图片、步骤、食材）

---

### 模块 5：个人中心

#### 5.1 用户信息
- 微信头像、昵称
- 用户标识码（如 38243244，用于邀请/识别）

#### 5.2 功能宫格（参考原版，按需裁剪）
- 厨房管理、新手教程、系统主题、提点意见
- 饮食计划、厨房冰箱、厨房菜篮、更多功能

#### 5.3 消息中心
- 订单通知（厨师接单/完成）
- 团队邀请
- 系统消息

```
TabBar（4个主入口，首版砍掉"发现"后置）

├── 团队管理页（创建/加入团队、成员列表、指定厨师）
├── 团队内点餐页（多人实时同步）
├── 订单详情页（含取餐码）
├── 厨师接单看板
├── 菜谱详情页
├── 厨房管理 / 冰箱 / 菜篮
└── 新手教程
```

## 六、状态流转

### 6.1 订单状态
```
待提交 → 已提交(待接单) → 已接单(制作中) → 待取餐 → 已完成
                                    ↓
                       可标记单道菜完成
```

### 6.2 厨师认领
```
订单提交 → [团队指定厨师] → 直接通知该厨师
         → [无人指定]     → 团队成员可"认领"做菜 → 成为该订单厨师
```
